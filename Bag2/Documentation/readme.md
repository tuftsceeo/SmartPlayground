# Documentation

System-level documentation for the Smart Playground Bag2 project.

## Contents

### COLOR_QUEST_README.md

Complete reference for the Color Quest multi-device game system. Covers the full communication architecture between the three ESP-NOW devices (hub station, wand module, and scoreboard), including message formats, wiring diagrams, score display scaling logic, and setup instructions.

Key topics covered:

- System architecture diagram showing ESP-NOW message flow
- Per-device hardware and role descriptions
- JSON message formats for station broadcasts and score submissions
- Scoreboard bar graph scaling and color palette
- Step-by-step deployment and MAC address configuration
- Timing behavior and edge cases
