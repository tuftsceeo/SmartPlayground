Smart Playground Wand

Game Icon Guide

A quick reference for kids and teachers using the wand. Each section is a separate game. Match the icon on the wand to the cards below to know what is happening and what to do next.

How to use it

  1. Pick the game you are playing.
  2. Find the icon that matches the wand.
  3. Follow the player action or teacher note.
Freeze DanceCaller sends dance and freeze commands. Cooking RecipesScan ingredients, then press the button to cook. Music MakerScan notes, then press the button to play back. Color CourseBeta: follow the landmark color sequence.
This guide uses player-friendly names and gameplay meanings. Code names, variable names, and animation frame counts are intentionally hidden.
