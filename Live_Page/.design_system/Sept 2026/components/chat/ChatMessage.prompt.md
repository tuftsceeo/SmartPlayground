One-line: the chat column's three bubble roles plus the code block the assistant returns.

```jsx
<ChatMessage role="user">make a game where shaking lights up the wand</ChatMessage>
<ChatMessage role="bot"><ThinkingDots />thinking…</ChatMessage>
<ChatMessage role="system">Try one of these ideas — tap a chip to fill the box, then edit and send:</ChatMessage>
```

Bubbles have a 3px "tail" corner pointing at their sender. System notes are 12px and never coloured.
