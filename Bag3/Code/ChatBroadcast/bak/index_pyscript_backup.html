How to Use the AI Wand Chatbot

1
Enter the Magic Code

When the app loads, type the passphrase your instructor gave you to unlock the AI.

2
Connect Your Wand

Plug in your wand via USB. Click Connect and select the serial port in the browser popup. You'll see the REPL output when connected.

3
Ask the AI to Write Code

Describe what you want the wand to do in the chat box. Example: "Make a rainbow animation that responds to shaking". The AI generates code and places it in the editor on the right. You can edit it and use the editor's green play button to test it on the wand.

4
Upload Your Code

Click Upload to save the code as jumpin.py on your wand. The wand resets and your code runs when you tap the "jumpin" NFC tag. Upload checks that your code has the correct format.

5
Browse Versions

Use the ◄ ► arrows above the editor to flip through previous code versions. Click Download to save any version to your computer.

6
Write NFC Tags

Click the gear icon ⚙ next to the Reset button to reveal the Write NFC Tag tool. This lets you write custom text to NFC tags for use with your games.
