# Game types: pick the row first

Before writing any code, **state the row in one line** ("Type 2: one wand, two Splats").
**Pick the simplest row that fits.** Priorities: simple, memorable, consistent, small memory.
A child can recall one or two starting steps, no more.

## Axis 1: who decides

| Value | Players | Joining | Child's start |
|---|---|---|---|
| alone | one child, or every child separately | none | tap the game card |
| leader | whole class; one wand or station sends, the rest follow | open | tap the game card |
| equal | whole class; every wand broadcasts | open | tap the game card |
| host | a limited group; a station runs a closed group | closed, at the host | tap the game card on the host |

## Axis 2: stations used

None, or one or more stations. A **Splat is a station**; a wand translates its Bluetooth.

| Translator | Splats | Use |
|---|---|---|
| the child's own wand | up to 2 | individual play |
| a Splat host wand | up to 4 | a group's station |

Pooled Splats (each wand bringing its own into a shared set) do not exist.

## Modifier: teams

None, a team **NFC card**, or a **teacher command**. Never assigned by a lobby.

## Types

| # | Example | Who decides | Stations | Notes |
|---|---|---|---|---|
| 1 | solo wand game | alone | none | default |
| 2 | cooking, ice cream | alone | 1-2 Splats on the child's wand | default when Splats are mentioned (wand device section, "Splats") |
| 3 | melody | alone | shared station, last write wins | not available yet: do not write |
| 4 | freeze dance | leader (teacher wand) | none | |
| 5 | freeze dance with music | equal, or the station leads | speaker or display | |
| 6 | team games | leader or equal | optional | plus teams |
| 7 | group game, wand lobby | host = a wand | none | **last resort**: young children cannot recall multi-step starts. Only when the teacher asks (plain lobby, end of `splat_host_games.md`) |
| 8 | group game at a station | host = the station | that station | teams optional |
| 9 | Splat host group game | host = Splat host wand | its up to 4 Splats | `splat_host_games.md` |

Types 1, 3-6 and 8 (player side) use the ordinary wand template. Driving an idle Splat
host from a wand game (station mode) is not available yet.

## Not supported

- More than 4 Splats in one group: run two groups.
- Several groups at once is fine: a child joins the host whose card they tap; host colors differ.
