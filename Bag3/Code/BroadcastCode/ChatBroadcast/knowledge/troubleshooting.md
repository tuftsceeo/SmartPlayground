# Troubleshooting — what lights, sounds and screens mean

Every meaning below is taken from the device firmware. If a teacher describes something that is not
listed here, say you don't know what it means, suggest the first safe step (turn the device off and
on, or send the game again), and suggest contacting the SmartPlayground team. Do not guess.

Most of the time the wand and the other devices are **not** connected to the computer, so the
teacher can only describe what they see and hear. Ask them what they see if the description is
unclear ("Is it a red X, or red bars?").

## Connecting to the app over USB

The only supported connection is a USB cable from the computer to the Broadcast Box, Dial or a
wand.

1. Use **Chrome or Edge** on a laptop or desktop. Other browsers, tablets and phones cannot
   connect.
2. Plug in the USB cable. Use a cable that carries data; some charging-only cables do not.
3. Click **Connect**, pick **Broadcast Box / Dial** or **Wand**, then choose the device in the
   browser's list.
4. If the device is not in the list: unplug it, plug it back in, and try again. Close any other
   browser tab that has this app open — only one tab can talk to the device at a time.
5. If it still does not connect, suggest contacting the SmartPlayground team. Do not suggest
   installing drivers or other software.

## Writing cards

Cards are written by the Broadcast Box or Dial, never by a phone or another app. After **Send to
Box**, the app says "Hold a card on the device to write it".

| Box / Dial screen | Meaning |
|---|---|
| "Tap Tag Now" (Box) / "Hold Card on Screen" (Dial) | Waiting for a card |
| "Writing …" "Hold Card Steady" | Writing — keep the card still |
| "… Written!" with a happy beep | Card is ready |
| "Already …" "No Change Needed" | The card already had that value; it is fine |
| "Write Failed" (red) with a low beep | Try again, holding the card flat and still |

## Wand

| What you see / hear | Meaning | What to do |
|---|---|---|
| **Red X flashes three times, with low beeps**, right after tapping a game card | The game could not start: the file has a mistake, or it is too big for the wand | Tell the assistant what happened. It will make a simpler or corrected version; send it again |
| **Red X once**, after tapping the card that gets a new game | Getting the game failed | Tap the card again, closer to the Box |
| **Red wifi bars** while getting a game | The Box is not sharing | On the Box, choose Share, then tap again |
| **Orange wifi bars** while getting a game | The wand could not join, or the Box does not have that game | Check the right game was sent to the Box; tap again |
| **Green check** | New game received | Tap the game's card to play |
| **Game suddenly stops** with no X and no special sound | The game hit a mistake while running (the wand shows nothing for this) | Tell the assistant what the children were doing when it stopped |
| **Low beep** after tapping a card | The wand does not know that card, or that game is not on this wand | Check the card; send the game to this wand |
| Middle lights **blink red** while idle | Battery is low | Charge the wand |
| During start-up, a start-up light **flashes red twice and stays red**, and the wand goes no further | The card reader did not start | Turn the wand off and on; if it repeats, contact the team |

When a wand is on, a short row of lights shows each start-up step. This is normal.

## Broadcast Box and Dial

| Screen | Meaning |
|---|---|
| "Starting" | Turning on or restarting — normal after a game is sent |
| "No Game Loaded Yet" | No game has been sent yet |
| "Sharing …", "Pickups: N" | Wands can get the game now; N wands have got it |
| "No Game to Serve" (red) | Share was chosen but there is no game on the Box — send one first |
| "Transfer Failed" (red) | A wand could not get the game; tap the wand again. If it always fails, the game may be too big — ask for a simpler version |

On the Box, a red battery line means the battery is at 15% or below.

## Splat Companion (light ring)

| Ring | Meaning |
|---|---|
| Dim blue | Turning on |
| Solid blue | Looking for the Splat — turn the Splat on and bring it close |
| Cyan, slowly glowing | Ready |
| Solid red that stays | The station cannot reach its radio board — contact the team |
| **Three quick red blinks** | The game could not start — ask the assistant for a corrected version |
| Green, then restart | New game received |
| Orange | Could not join the Box, or the Box does not have that game |

## Icon display

| Picture | Meaning |
|---|---|
| Green square | Ready, no game running |
| **Red X** for about a second | The game could not start — ask for a corrected version |
| Amber "?" | The display does not know that card, or that game is not on it |
| Green check | New game received |
| Red / amber wifi bars | Same as on the wand: the Box is not sharing / could not join or no such game |

## When the assistant should say "I don't know"

- A light, sound or screen not listed above.
- Anything about fixing the firmware, re-flashing a device, or changing library files.
- Hardware damage, charging problems beyond "charge it", or a device that will not turn on.

In each case, say so plainly and suggest contacting the SmartPlayground team.
