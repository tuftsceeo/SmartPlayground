# Bag3/Code/BroadcastCode/docs_and_design

This folder is for test logs and plans that are in active use by agents and historical records of past sessions. 

Only the data in folders that were made by the current session, provided as a specific reference, or have a date within the last 5 days is likely salient to current work.

Hygiene: When design, testing or other session work related to the note completed, flag documents with:
```
---
status: historical
note: >-
  Old development note, kept as a record. Not current guidance: rules, paths and plans
  here may be out of date. Check AGENTS.md and the code for current behavior.
---
```
