One-line: the three text inputs the product has — a labelled name field, the gallery search, and the round chat composer.

```jsx
<TextField label="Name this game" pencil placeholder="Game name" maxLength={48} />
<SearchInput placeholder="search games…" />
<ChatInput placeholder="type a request…" />
```

Placeholders are lowercase with an ellipsis. Focus turns the border pink with a 3px pink ring.
