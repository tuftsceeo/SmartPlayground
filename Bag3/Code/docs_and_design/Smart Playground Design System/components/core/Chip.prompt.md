One-line: pill filters above the gallery grid (Chip) and tappable prompt suggestions in chat (StarterChip).

```jsx
<Chip active>All</Chip>
<Chip icon="music">Sound</Chip>
<StarterChip icon="rainbow">a game where shaking makes a rainbow</StarterChip>
```

StarterChip copy is lowercase and phrased as the child's own words. Hover tints it pink.
