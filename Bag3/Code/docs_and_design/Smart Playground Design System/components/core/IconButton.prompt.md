One-line: 14px-radius outline square for footer/drawer tools; SendButton is the 38px round pink composer button.

```jsx
<IconButton icon="save" title="Save" />
<IconButton glyph="</>" title="Show code" active />
<SendButton onClick={send} />
```

Hover turns the border and glyph purple. Always give a `title` — these are unlabelled.
