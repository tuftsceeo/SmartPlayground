# PN5180 on M5Capsule v1.1

`Experiments/Capsule PN5180/lib/pn5180.py` is a drop-in for MockWand's `lib/pn532.py`: same
methods and return shapes, so `NfcReader` and `read_ndef_text` run unchanged. Only the
constructor differs: `PN5180(spi, nss=, busy=, rst=)`. `nfc_reader.py` imports
`MIFARE_AUTH_A/B` from `pn532`; a host can alias the module with
`sys.modules['pn532'] = pn5180`.

## Wiring as tested

| PN5180 | Capsule |
|---|---|
| +5V | Grove port 5 V (red) |
| +3.3V | header pin 8, 3V3 |
| GND | header GND |
| SCK | G7 |
| MOSI | G43 (UART0 TX; the boot ROM log goes out on it while NSS is high) |
| MISO | G44 |
| NSS | G3 |
| BUSY | G1 |
| RST | G9 |

SPI host 2, mode 0. `begin()` returns `(4, 4, 0)`: product 4, firmware 4.0.

## Corrupted card replies

About 1 in 5 frames from the card has RX_STATUS data-integrity, protocol or collision bits set
(`0x001C0000`). The driver drops those frames, checks the anticollision BCC, and retries block
reads up to 3 times. The card stays authenticated across a lost reply.

Measured 2026-10-28 with one MIFARE Classic card (UID 21:54:61:66, NDEF text `relaycolor`)
resting on the reader. 40 WUPA + anticollision cycles per row; NDEF reads use
`read_ndef_text`:

| Condition | Clean cycles | Reselect | NDEF reads |
|---|---|---|---|
| Card flat on antenna | 27-35/40 | 20/20 | 14/20, 0.2-0.5 s each |
| Card 1 cm above antenna | 4-17/40 | 13-14/20 | 3/20 |

Ruled out:

- SPI: 200 EEPROM reads per clock at 250 kHz, 1, 2, 4 and 7 MHz, 0 errors.
- Timing: SPI clock, 3 vs 10 ms reply wait, and field-reset timings (5/5, 5/20, 20/20 ms off/on)
  do not change the error rate.
- Over-coupling: raising the card makes it worse, not better.

Remaining hypotheses, in order: noise on the transmitter's 5 V supply (Grove 5 V over long
jumpers), ground noise over the single long ground jumper, receiver settings for this module.

## Splat tags

The tags on the Splats are detected (UID read, e.g. `C1:37:E6:B1` SAK 21, `61:EC:CA:A8` SAK 0B)
but not read. SAK 0B returned `Read err` on NTAG page reads 0 and 4. Neither SAK is MIFARE
Classic (08/18), so `NfcReader` takes its NTAG path for them.

## NfcReader raises UnicodeError on corrupted NDEF

`_decode_ndef_text` in MockWand `lib/nfc_reader.py` calls `.decode('utf-8', 'replace')`.
MicroPython ignores the errors argument and raises `UnicodeError` on invalid UTF-8, so a
partly corrupted read propagates out of `read_command` instead of returning `None`. Seen on
card 60:9B:F3:58. The bench demo catches it; the MockWand copy is unchanged.

## Bench notes

- `mpremote ... resume` keeps imported modules between runs. Test scripts pop `pn5180`,
  `nfc_reader`, `game_tags` and `pn532` from `sys.modules` first, or an edited driver does not
  load.
- Stopping the host side of `mpremote mount ... run` mid-script leaves the Capsule hung on the
  mounted filesystem; Ctrl-C and `esptool` reset did not recover it, and the USB port
  disappeared until the board was unplugged.
- The tag-read beeps in the bench scripts follow MockWand: start tune `SOUNDS["start"]`,
  1200 Hz 50 ms for a recognised command, 400 Hz 80 ms otherwise. The Capsule buzzer is on G2.
