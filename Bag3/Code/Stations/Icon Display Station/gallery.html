Icon Library Gallery

Simulated-LED previews of every 16×16 icon in icons/ -- reference before flashing. Renders assume INTENSITY=0.30; see each icon's maps/<name>.json.

Generated by hand_author_icons.py (new icons) and image_to_icon.py (photo-derived icons) in this directory. The "new" badge marks icons added for the kid-facing built-in library pass -- everything else predates it. Source of truth for pixel data is icons/<name>.py; edit maps/<name>.json and re-run the generator rather than hand-editing an icon file.
