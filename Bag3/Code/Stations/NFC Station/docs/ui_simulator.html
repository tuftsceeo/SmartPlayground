Letter ring. All 30 items on the rim, one detent each; the highlight stays after a click, so repeated and nearby letters cost no turns. Slots are sized to each glyph's width, which is why m and w get wider cells.

    
Zone + multi-tap. Adapted from Crownboard's out-of-vocabulary mode: the dial moves a zone of three, a click opens it, the three letters appear in the centre, the dial picks one and a click enters it. Crownboard auto-scans zones every 1,000 ms and uses a double-press; a rotary encoder lets the user turn instead, so no timing is needed. Fewer detents per letter, one extra click.
