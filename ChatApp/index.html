How to Use the AI Wand Chatbot

1
Enter the Magic Code

When the app loads, type the passphrase your instructor gave you to unlock the AI.

2
Connect Your Wand

Plug in your wand via USB. Click Connect and select the serial port in the browser popup.

3
Ask the AI to Write Code

Describe what you want the wand to do. The AI generates code and places it in the editor.

4
Upload Your Code

After code is generated, choose a slot (1–5) and click Upload. Each slot maps to an NFC tag that triggers it.

5
Browse Versions

Use the ◄ ► arrows above the editor to flip through previous code versions.

6
Write NFC Tags

Click the gear icon ⚙ to reveal the Write NFC Tag tool for writing custom text to NFC tags.
